# RefPunch

Browser mix desk: drop your bounce and a reference track, get a punch list.

Audio stays in the tab. Web Audio API measures loudness, crest, brightness proxy, and energy shape, then writes notes you can take into MixForge or a DAW.

## Pricing
- Desk — free, one compare
- Pro — $12/mo
- Forge — $79 lifetime

## Run
Open `index.html` or deploy the folder as a static site on Vercel.
